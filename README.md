# Sales Performance Dashboard 📊

## Overview
An end-to-end Excel dashboard project that tracks and visualizes the daily sales 
performance of sales executives across multiple regions in India.

## Dataset
| Column | Description |
|--------|-------------|
| Emp Code | Unique employee identifier |
| Sales Executive | Name of the sales rep |
| Region | City/region assigned |
| Day1 – Day5 | Daily sales figures |
| Total Sales | Sum of daily sales |
| Target | Assigned sales target |
| Target Hit % | Percentage of target achieved |
| Away From Target % | Gap remaining from target |

## Features
- 📌 **Pivot Tables** — 4 pivot tables summarizing sales by region, executive, and performance
- 📈 **Charts** — Visual comparison of actual sales vs targets
- 🎛️ **Slicers** — Interactive filters to drill down by region or executive
- ⚡ **VBA Macros** — Automation for dashboard interactivity
- 🗺️ **Multi-region Coverage** — Mumbai, Delhi, Chennai, Pune, Nagpur, Patna, Ranchi, Surat

## Tools Used
- Microsoft Excel (Pivot Tables, Charts, Slicers, VBA)
